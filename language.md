Lang features
- Anonymous functions
- Regular functions
- Tail call optimisation
- If, else
- Variables (ints, strings, lists)
- Zephyr FFI
- Single threaded

Grammar
- Default variable to int (myVar = 1)
- String if detected "" (myVar = "hello world")
- List if detected [] (myList[2] = [0, 1]), list type determined by first item in list, if other items in list arent same type, throw error
- function declaration fn -> : (fn functionName -> input1 input2 : output)
- tail recursion declaration ts
